# راه‌اندازی CloudCLI روی کامپیوتر خودتان (بدون هیچ دانش فنی)

CloudCLI یک چت هوشمند خصوصی است که روی **کامپیوتر خودتان** اجرا می‌شود و با اکانت
کلاد (یا کلیدهای خودتان) کار می‌کند. هیچ چیزی نصب نمی‌کند؛ فقط یک پوشه است.

## شروع (۳ قدم)

1. **فایل ZIP نسخهٔ سیستم خودتان را دانلود کنید** — ویندوزی‌ها نسخهٔ `win-x64`،
   مک‌های جدید `darwin-arm64`، لینوکس `linux-x64`.
2. **استخراج کنید**: روی فایل ZIP راست‌کلیک → *Extract All* (ویندوز) یا دوبار کلیک
   (مک/لینوکس). یک پوشه ساخته می‌شود.
3. **دوبار کلیک کنید**:
   - ویندوز: `Start-CloudCLI.bat`
   - مک: `Start CloudCLI.command`
   - لینوکس: `start-cloudcli.sh`

یک پنجرهٔ سیاه باز می‌شود، چند لحظه صبر کنید تا خودکار مرورگر و سایت باز شود.
**این پنجره را نبندید** — باز بودن همان پنجره یعنی برنامه روشن است.

## ورود به سایت

نام کاربری و رمز در فایل `data/LOGIN.txt` داخل همان پوشه نوشته شده
(پیش‌فرض کاربری: `admin`).

## وصل کردن هوش مصنوعی (یک بار، اولین بار)

1. داخل سایت، بالای صفحه روی **Settings** بزنید.
2. قسمت **Claude** را پیدا کنید و **Sign in** را بزنید.
3. یک صفحهٔ ترمینال (خط‌های سیاه) داخل سایت باز می‌شود و یک **لینک** نشان می‌دهد.
4. آن لینک را کپی کنید، در مرورگر باز کنید، با اکانت Claude خودتان وارد شوید و
   **کدی** که می‌دهد را برگردانید و همان‌جا پیست کنید (Ctrl+V سپس Enter).
5. پیام موفقیت ظاهر شود، از آن به بعد فقط چت کنید.

از این پس مکالمه روی اشتراک خودتان است، نه روی هیچ سرور دیگری.

## سؤال‌های رایج

- **ویندوز هشدار آبی (SmartScreen) داد؟** روی *More info* then *Run anyway* بزنید.
  این هشدار فقط به‌این دلیل است که فایل جدید است و امضای دیجیتال ندارد.
- **مک گفت نمی‌شود باز کرد؟** دوبار کلیک نکنید؛ **راست‌کلیک → Open → Open**.
- **برنامه را چطور خاموش کنم؟** پنجرهٔ سیاه را ببندید.
- **داده‌هایم کجاست؟** همه‌چیز داخل همان پوشه (`data` و `workspace`). بکاپ = کپی
  همین پوشه. حذف کامل برنامه = حذف همین پوشه.
- **اینترنت می‌خواهد؟** فقط برای گفتگو با هوش مصنوعی و دانلود اولیه.
